# ADR-3 — Institutional Navigation Blueprint

## Purpose

The Admin page is being reconstructed into an Institutional Command Center. The goal is to preserve all existing entry points while organizing them into a clear workspace-based navigation system.

## Top-Level Navigation

1. HOME
2. CREATE
3. ADMINISTER
4. LEGACY
5. LEARN
6. REPORTS
7. SYSTEM

## HOME

Primary purpose: orient the user and resume work.

Entry points:
- Resume Process
- Recommended Next Action
- System Snapshot
- Recent Activity
- Continue Existing Work

## CREATE

Primary purpose: begin new institutional work.

Entry points:
- Start New Intake
- Create Trust
- Import Existing Trust
- Generate Document
- Create Workspace
- New Task

## ADMINISTER

Primary purpose: operate active trusts and matters.

Entry points:
- Existing Trust Operations
- Trust Registry
- Matters
- Assets
- Funding
- Execution
- Transfers
- Trust Minutes
- Certificate Registry
- Form 1041
- Financial Summary

## LEGACY

Primary purpose: support the family legacy application.

Entry points:
- Genealogy
- Media
- Workspace
- Discussions
- Family Records
- Legacy Vault
- Oral Histories
- Historical Documents
- Family Timeline

## LEARN

Primary purpose: provide guidance, education, and institutional knowledge.

Entry points:
- Learning Hub
- Trust Types
- Forms Guide
- Video Tutorials
- Learning Articles
- Playbooks
- Checklists
- New Learning Article
- New Form Guide
- Upload Video

## REPORTS

Primary purpose: exports, reports, audit trails, and institutional records.

Entry points:
- Report Center
- Portfolio PDF
- Audit Log PDF
- Fiduciary PDF
- Lifecycle Ledger
- Export Center
- Archive
- Audit Trail

## SYSTEM

Primary purpose: platform control, safety, and administration.

Entry points:
- System Health
- Security
- Permissions
- Users
- Database Backup
- Policy Controls
- Railway Readiness
- Hosted Baseline Seed

## Design Rules

- Keep all existing entry points.
- Remove duplicate link clusters where possible.
- Organize by user intent, not technical module names.
- Make the first question: “What would you like to do today?”
- Treat Trust Administration and Family Legacy as two connected apps inside one institutional platform.
- Keep pilot safety notices visible but less dominant.
- Keep policy controls available but move them into SYSTEM.
- Keep test trust deletion policy parked under ADR-2A as a later supporting adjustment.
