# ADR-6 — Institutional Dashboard Shell Blueprint

## Purpose

Convert the Admin Dashboard from one long page into an institutional operating shell.

## Core Rule

Do not remove existing routes.

Do not delete legacy tools.

Do not break current workflows.

Reorganize them into focused workspace regions.

## Primary Shell Workspaces

1. HOME
2. CREATE
3. ADMINISTER
4. LEGACY
5. LEARN
6. REPORTS
7. SYSTEM

## HOME

Institution health, recommended next action, system snapshot, alerts, recent activity.

## CREATE

Start New Matter, Intake, Create Trust, Generate Documents, Instrument Registry.

## ADMINISTER

Matter operations, trust operations, funding, execution, assets, fiduciaries, minutes.

## LEGACY

Genealogy, media, family history, workspace, discussions, archives.

## LEARN

Learning hub, trust types, forms, videos, playbooks.

## REPORTS

Report center, audit reports, certificates, exports, archive proof.

## SYSTEM

Users, permissions, security, backups, policies, system health.

## Design Principle

The Institutional Command Center becomes the primary navigation shell.

Legacy shortcuts become compatibility tools only.
