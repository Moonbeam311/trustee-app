# IIA-4 — Institutional Relationship Architecture (IRA)

## Purpose

Define the canonical relationship architecture for the Trustee App.

IIA-1 defines where information belongs.

IIA-2 defines workflow.

IIA-3 defines institutional objects.

IIA-4 defines how those objects relate.

Relationships are first-class institutional records.

They are never implied.

They are explicitly modeled, verified, versioned, audited, and preserved.

---

# Core Principle

Nothing exists in isolation.

Everything is connected.

The institution is a living relationship graph.

---

# Canonical Relationship Rule

Every institutional object must be capable of participating in one or more relationships.

Relationships themselves are institutional records.

Relationships have their own:

- ID
- lifecycle
- verification
- evidence
- timeline
- audit history
- provenance
- permissions

---
