# IIA-2 — Institutional Workflow Architecture (IWA)

## Purpose

Define the canonical workflow architecture for every institutional process within the Trustee App.

This document governs how work moves through the institution regardless of record type.

The workflow shall be consistent whether operating on:

- Trusts
- Matters
- Estates
- People
- Organizations
- Assets
- Instruments
- Research Projects
- Compliance Reviews
- Governance Decisions
- Archive Packages

---

# Core Principle

Every institutional object follows the same lifecycle.

The object changes.

The workflow does not.

# Workflow Rules

Rule 1

Nothing bypasses Review.

Rule 2

Nothing bypasses Archive.

Rule 3

Everything produces Timeline history.

Rule 4

Everything generates Audit history.

Rule 5

Everything belongs to an institutional owner.

Rule 6

Every record is relationship-aware.

Rule 7

Every action becomes evidence.

---

# Success Criteria

The Institutional Workflow Architecture is complete when:

- Every module follows the same lifecycle.
- Workflow is independent of record type.
- Governance, review, execution, reporting, and archive are mandatory architectural stages.
- New institutional capabilities can be added without inventing new workflow models.
