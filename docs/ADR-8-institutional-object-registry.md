# ADR-8 — Institutional Object Registry

Defines canonical institutional objects.

Primary objects:
- Trust
- Matter
- Person
- Organization
- Role
- Asset
- Instrument
- Relationship
- Decision
- Discussion
- Evidence
- Archive Record
- Report
- Task
- Event
- Workspace
- Research Project
- Compliance Review
- Funding Record
- Execution Record

Rule: new features must attach to a canonical object instead of inventing isolated page logic.
